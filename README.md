DB와 서버 없이 브라우저에서 체험하는 쿠지 샘플입니다. **체험 시작**을 눌러 상품 선택 → 쿠지판 → 샘플 구매·뽑기 → 결과·내 쿠지기록을 확인할 수 있습니다. **관리자 체험**으로 관리 화면도 살펴볼 수 있습니다.

**2026-10-16 최신 업데이트:** 기존 귀멸의 칼날·진격의 거인·체인소맨 샘플도 실제 발매된 귀멸의 칼날 ~상현의 이~, 진격의 거인 ~선택과 결과~, 극장판 체인소맨 레제편 제2탄으로 교체했습니다. 드래곤볼 GT, 원피스 엘바프편 GIANT BASH!! Vol.2, 나루토 질풍전 풍영 탈환편, 애니메이션 주술회전 5주년 FINAL!까지 총 공식 7종·72개 경품·공식 이미지 295개를 포함합니다. 상품별 포스터·이미지·한국어 요약·크기·종류·디자인 선택 여부·발매일·일본 정가·자료 출처·권리자를 확인할 수 있습니다.

이전 3종에서 뽑은 상품을 새 경품으로 바꾸지 않도록 기존 판·등급·당첨·선물·지갑·진행 세션·관리자 설명은 ‘이전 샘플’로 보관합니다. 발매종료 목록에서 이전 판을 확인하고 구매해 둔 뽑기를 이어갈 수 있으며, 이전 판의 신규 구매는 차단합니다. 새 브라우저에는 대체된 이전 3개 샘플을 만들지 않습니다.

일본 공식 정가와 프로그램의 원화 가격을 구분합니다. 새 상품의 원화 가격·판별 수량·재고는 체험용 예시이며 실제 판매처 재고와 연동되지 않습니다. 라스트원상과 공식 더블 찬스는 일반 추첨 티켓에 포함되지 않습니다. 각 상품의 공식 원문은 화면의 출처 링크를 참고해 주세요.

실제 결제·상품 제공·회원가입·외부 메시지 전송은 이루어지지 않습니다. 변경 내용은 현재 브라우저의 localStorage에만 저장되며 **샘플 초기화**로 되돌릴 수 있습니다. 브라우저 저장소를 사용할 수 없으면 현재 화면을 연 동안만 유지됩니다.

이 저장소에는 공개 데모용으로 컴파일된 프론트엔드 파일만 포함합니다. 원본 소스·백엔드·DB·환경 설정 파일은 포함하지 않습니다. 실제 운영 서비스에는 별도 서버와 DB가 필요합니다.
