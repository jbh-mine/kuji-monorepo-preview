# Kuji 공개 데모

[쿠지 사이트 열기](https://jbh-mine.github.io/kuji-monorepo-preview/)

초기 수록(2026-10-16): 공식 쿠지 17종(발매 12종·예정 5종), 전체 경품 169개와 예고 경품 2개, 공식 이미지 529개를 수록했습니다. 헌터×헌터와 나의 히어로 아카데미아로 남은 나히야·헬싱 샘플을 교체하고 데스노트·블리치·하이큐를 추가했습니다. 기존 귀멸의 칼날·진격의 거인·체인소맨·드래곤볼·원피스·나루토·주술회전도 실제 공식 상품의 정식 한국어 제목·일본어 원제로 표시합니다. 포스터·경품 사진·크기·종류·설명·발매일·일본 정가·원문 출처를 확인할 수 있습니다.

드래곤볼 신규판, 진격의 거인, 나루토, 원피스, 데스노트 2탄은 발매 예정에 수록했습니다. 데스노트 2탄은 공개된 예고 경품만 표시하고 전체 구성을 추정하지 않습니다.

**매일 오전 10:10(한국/일본 시간)** GitHub Actions가 공식 발매 달력과 상품 페이지를 확인해 변경 정보·이미지를 저장하고 사이트를 배포합니다. GitHub 스케줄은 지연될 수 있습니다. 앱은 시작할 때와 매시간 갱신 자료를 불러오고, 확정된 발매일에 예정 → 발매중으로 이동합니다. 미정 날짜나 미공개 경품은 임의로 채우지 않습니다. [자동 갱신 운영 설명](DAILY-CATALOG.md) · [갱신 실행 내역](https://github.com/jbh-mine/kuji-monorepo-preview/actions/workflows/daily-catalog.yml)

자동 추가되는 쿠지명·경품명·상품 설명·사양·캠페인을 한국어로 번역하고 일본어 원제와 경품 원명도 함께 표시합니다. 현재 자동 수집 상품을 포함한 29종에 적용했습니다. 원문이 바뀌면 번역도 갱신하고 일시적 번역 오류는 다음 실행에서 재시도합니다.

상품 목록부터 쿠지판·현황·결과·뉴스·로그인·관리자까지 전체 화면을 모바일·태블릿·넓은 모니터에 맞춰 표시합니다. 각 페이지 상단의 ‘뒤로’ 버튼으로 이전 화면과 선택한 목록 탭으로 돌아갑니다. 구매한 세션·남은 뽑기·타이머는 뒤로 이동해도 유지합니다.

기존 샘플 판·당첨·선물·지갑·진행 세션과 관리자 수정은 보존합니다. 종료 목록에서 이전 판을 확인하고 구매해 둔 뽑기를 이어갈 수 있습니다. 기존 당첨 경품을 다른 경품으로 바꾸지 않도록 추첨 이력이 있는 상품의 경품 구성이 바뀌면 별도 판으로 추가합니다.

DB 없이 브라우저에서 체험하는 데모입니다. **체험 시작**으로 상품 → 쿠지판 → 샘플 구매·뽑기 → 기록을 확인하고 **관리자 체험**으로 관리 화면을 볼 수 있습니다. 원화 가격·티켓 배분·재고는 체험용 예시이며 실제 판매처 재고와 연동되지 않습니다. 실제 결제·상품 제공·회원가입·외부 메시지 전송은 없습니다. 변경 내용은 현재 브라우저에 저장되며 **샘플 초기화**로 되돌릴 수 있습니다.

이 저장소에는 컴파일된 앱, 공개 공식 자료, 일간 갱신 스크립트·테스트·배포 워크플로를 포함합니다. 비공개 앱 원본·백엔드·DB·환경 설정 파일은 포함하지 않습니다. 이미지와 캐릭터의 권리는 각 권리자에게 있습니다.
